## Codebase Patterns
- Use rattler-build recipe.yaml format (not conda-build meta.yaml)
- deadline-cloud.yaml lists sourceArchiveFilename and sourceDownloadInstructions for manual downloads
- Maya plugin recipes use `usr/autodesk/modules/maya/<version>/` for .mod files so Maya auto-loads plugins
- build.sh uses `set -xeuo pipefail` and references `$PREFIX`, `$SRC_DIR`, `$PKG_VERSION`
- Plugin recipes depend on `maya 2026.*` in both build and run requirements
- MayaUSD .run installer is Makeself 2.3.0 containing an RPM, not a direct file tree
- RPM extraction: `rpm -ivh --nodeps --noscripts --root $DIR file.rpm` (no cpio needed)
- RPM installs to: /usr/autodesk/mayausd/maya2026/<build_version>/mayausd/{MayaUSD_*,USD_*}
- The .mod file uses %MULTI_USD_VERSION% and <PLUGIN_DIR> placeholders
- Plugin has multi-USD-version layout: MayaUSD_0.24.11, MayaUSD_0.25.5, USD_0.24.11, USD_0.25.5
